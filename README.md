# Triple AAA Web

Sitio corporativo interactivo para **El Exclusivo**, desarrollado con Astro, TypeScript y GSAP.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

La carpeta `dist/` puede desplegarse como assets estáticos en Cloudflare Workers o Cloudflare Pages.

## Configuración pendiente

En `src/pages/index.astro`, reemplaza `WHATSAPP_NUMBER` por el número comercial en formato internacional, sin `+`, espacios ni guiones.
